# 結帳串接 Google Sheet（Apps Script）

網站結帳 → `fetch` POST → Apps Script Web App → 寫入 Google 試算表（＋選用的 Email 通知）。

```
index.html 結帳表單
   │  POST（JSON，Content-Type: text/plain 避免 CORS 預檢）
   ▼
Apps Script Web App（gas/Code.gs）
   ├─ 驗證欄位、用伺服器價目表重算金額、擋掉重複送出
   ├─ LockService 保護下產生訂單編號 GT260101-001
   ├─ 寫入「訂單」「訂單明細」兩張工作表
   └─ （選用）寄新訂單通知信給店家
```

## 部署步驟（約 5 分鐘）

1. 建立一份新的 Google 試算表（名稱隨意，例如「金黃鍋貼訂單」）。
2. 試算表上方選單 **擴充功能 → Apps Script**，把預設的 `Code.gs` 內容整份換成本資料夾的 `Code.gs`。
3. （選用）修改最上方 `CONFIG.NOTIFY_EMAIL` 填入店家收件信箱，才會寄新訂單通知。
4. 編輯器上方函式選單選 **`setup`** → 按 **執行**，依畫面完成授權（會看到「Google 尚未驗證這個應用程式」→ 進階 → 前往）。
   完成後試算表會出現「訂單」「訂單明細」兩張工作表。
5. 右上角 **部署 → 新增部署作業 → 類型選「網頁應用程式」**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（客人不需登入才能下單；這個網址只能「送出訂單」，無法讀取試算表內容）
6. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
   用瀏覽器直接開它，看到 `{"ok":true,"service":"jinhuang-orders",…}` 就代表部署成功。
7. 打開 `index.html`，找到 `const ORDER_ENDPOINT = '';`，貼上網址，存檔並重新部署網站。

> 之後如果修改了 `Code.gs`，要 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**，網址不變、新程式才會生效。

## 試算表欄位

**訂單**：訂單編號、建立時間、狀態（下拉：待處理／製作中／已完成／已取消）、用餐方式、姓名、電話、送貨地址、備註、品項摘要、總金額、請求ID  
**訂單明細**：訂單編號、品項代碼、品名、單價、數量、小計（方便用樞紐分析表統計熱銷品項）

店家日常只要改「狀態」欄即可追蹤進度。

## 重要提醒

- **改價錢要兩邊一起改**：`index.html` 的 `MENU_DATA`／禮盒價格，以及 `Code.gs` 的 `MENU`。兩邊不一致時，伺服器會回「價格已更新，請重新整理頁面」並拒絕該筆訂單。
- 新增／下架品項同理：伺服器收到不在 `MENU` 裡的品項代碼會拒絕。
- 訂單含客人姓名、電話、地址，**請勿公開分享這份試算表**，只分享給店內需要的人。
- Apps Script 免費額度：一般 Gmail 帳號每天可寄約 100 封通知信；同時多人下單時由 `LockService` 排隊處理，單筆約 1～2 秒。
- 目前沒有線上金流：訂單只代表「客人送出訂購意願」，付款方式（現場付款／匯款／貨到付款）要另外約定。
